
## Feature 2: Full-screen instructor messages

Improve instructor messages displayed on student computers.

Support at least these message types:

* Informational message
* Student warning
* Transition-time message
1
Requirements:

* Display messages in a true full-screen student overlay.
* Cover the full usable screen.
* Keep the message above ordinary application windows using documented Windows APIs.
* Clearly identify the overlay as an iD Tech classroom message.
* Do not disguise it as a system warning.

For student warnings and transition-time messages:

* Do not provide a student dismiss button.
* Keep the overlay active until:

  * The instructor disables it, or
  * Its configured timeout expires
* If the overlay window is accidentally closed or crashes while the message remains active on the server, recreate it.
* Do not recreate it after the instructor has disabled it.
* Reconnection must query authoritative server state so stale messages do not return.
* Do not make the process hidden or administrator-unkillable.

For informational messages:

* Preserve normal dismissal behavior if that matches the current design.

Where reasonably compatible with the current project:

* Display enforced messages across all active monitors.
* Handle monitor connection and removal.
* Keep message text legible and properly scaled.
* Prevent HTML or script injection in message content.
